# Jericho Overthrown Publishing — Homepage

Static HTML/CSS/JavaScript implementation of the approved homepage concept.

## Files
- `index.html` — homepage markup
- `styles.css` — responsive styling
- `script.js` — mobile navigation, active navigation, newsletter demo
- `assets/logo.png` — client-approved logo supplied in the conversation

## Deploy
Upload the contents of this folder to the site's public web root (for example `public_html`) and open `index.html`.

## Images
The hero currently uses a live Unsplash image URL as a temporary visual. The book covers are CSS-generated placeholders so you can replace them later with the client's actual book covers without changing the layout.

## Before production
Replace:
- placeholder contact details
- placeholder book titles/descriptions
- newsletter form handler
- resource/service links
- temporary hero image
- social links
- Privacy Policy / Terms links
